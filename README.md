# 💼 Frontend React Job Portal

A modern and responsive Job Portal web application built using **React.js** and **Vite**.  
This project allows users to browse job listings, search jobs, and explore detailed job information through a clean and user-friendly interface.

---

## 🚀 Live Demo

🔗(https://kashmir-careers.netlify.app/)


---

## 📌 Features

- 🔍 Job Search Functionality
- 📄 Detailed Job Description Pages
- ⚡ Fast Performance with Vite
- 🎨 Modern UI with Tailwind CSS
- 🔁 Dynamic Routing using React Router
- 📱 Fully Responsive Design

---

## 🛠️ Tech Stack

- React.js
- Vite
- Tailwind CSS
- React Router DOM
- JavaScript (ES6+)
- HTML5 & CSS3
